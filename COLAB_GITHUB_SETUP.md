## How to Use

### Method 1: Direct Links (Easiest)
1. Click one of the links above
2. Notebook opens in Colab
3. Enable GPU (Runtime → Change runtime type → T4 GPU)
4. Run cells

### Method 2: From Colab Homepage
1. Go to https://colab.research.google.com/
2. Click "GitHub" tab
3. Enter: `Westcoastrenmen/Vibemv`
4. Select notebook from list

### Method 3: From VibeMV Space
1. Go to your HuggingFace Space
2. Browse files
3. Click on `.ipynb` file
4. Click "Open in Colab" button

## When I Update Notebooks

**Before you start working:**
1. Open the Colab link
2. Click: File → Save a copy in Drive (optional - to save your work)
3. Or just use the GitHub version directly

**If I push a fix:**
1. In Colab: File → Revert to checkpoint → Latest from GitHub
2. Or just close and re-open the link
